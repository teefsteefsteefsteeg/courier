## 5. Known issues and caveats
- **Not playtested by a human.** Feel (movement, dash, typewriter speed, shop flow) is unverified.
- **Scene-embedded Merchant leaks at exit.** Putting `merchant.gd` inside an NPC scene file made
  Godot report ~263 leaked objects (scripts, animations, materials) at exit, even with the
  Merchant inert. Root cause not found, probably a script reference cycle. Workaround:
  attach Merchants at runtime (as ShopUI does for the Armory) or use `merchant_counter.tscn`
  placed directly in a level. If you add a Merchant to a scene file, check `--quit-after` output
  for leak reports.
- **The role branches still have two fixed-on-integration bugs.** `phase5f-gameplay-ui` still has
  the non-deferred `Merchant._ready` and `tools/.gdignore`. Continue from `phase5f-integrated`, or
  port `28e3e77` back.
- **Save:**
  - A delivery in progress (and its carried package) is lost on quit; the contract is offered
    again.
  - There's no in-game New Game; use `-- --new-game`.
  - In normal windowed play the save file is real, so playtests carry progress between launches.
- **Economy and gear:**
  - The FREE animation pack has no swing clips: melee reuses Interact (sword) and Throw (axe).
  - The Phase 4 combat panel still labels the primary attack "Bolt" for every weapon.
  - Item icons are placeholders.
  - Unequipping the shield can leave current shield durability above the new max until used.
  - Ranks gate nothing yet.
- **Dev mode:** 500 starting gold in any debug build with a window, including debug exports.
  Headless test runs are never dev mode.
- **Input prompts:**
  - The sheet lacks I, O, P, T, U, Y, 0, 7-9 (drawn fallback keycaps).
  - Pixel icons scale unevenly when the window isn't 1600x900 (non-integer `canvas_items` stretch).
  - The Phase 3 exhibit's 3D `[E]` sign and the combat HUD still use text.
- **Layout:** on canvases narrower than about 1100 px the 960 px dialogue box reaches the left edge,
  so the WASD guide hides while dialogue is open.
- **Rendering:** quest markers draw without depth test, so they show through walls.
- **Fonts:** `✓` and `▸` rely on system font fallback; the project bundles no font.
- **`.import` churn:** each Godot run rewrites vendor `.import` files with LF endings (no content
  change). Don't commit it.
- **`TODO.md`:** older phase follow-ups listed there (shadow tuning, portrait art, occluders for
  small props, NPC body type) are still open.

## 7. Conventions worth knowing
- **Services:** found by group (`QuestManager.find(get_tree())` etc.); no autoloads.
  `GameplayServices` is the first child of the level.
- **Modals:** join `ui_modal`; the prompt, dialogue, journal and map all respect it.
- **Hint text:** comes from `InputHints.key_for(action)` (`"[E] Talk"`); `InputPromptLabel` renders
  it with keycaps. Tests read `label.text`, so keep that format.
- **Tests:** each test file is a `SceneTree` script whose exit code is its failure count. Prefer
  the real village (`res://scenes/levels/village.tscn`) and real input (`Input.action_press`,
  `Input.parse_input_event` + `flush_buffered_events`).
- **Generated scenes:** buildings and the Armory are generated; edit `tools/generate_*.gd` and
  regenerate. Use `MergedProp` / `MedievalBuilding.merge_model` for batching.
- **Asset licences:** record every new asset in `ASSET_MANIFEST.md`.
